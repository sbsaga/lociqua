# Contributing to Lociqua

Thank you for improving Lociqua. Before opening a pull request:

1. Keep data acquisition lawful and source-specific.
2. Do not add bypass, stealth, CAPTCHA, or restriction-evasion features.
3. Add tests for behavior changes.
4. Do not commit secrets, datasets without distribution rights, or personal data.
5. Run `python -m unittest discover -s tests -v`.

Use focused pull requests with a short explanation of the user problem solved.
