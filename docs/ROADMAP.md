# Roadmap

## Available now

- Local dashboard and API.
- CSV preview, bounded import, normalization, provenance, and export.
- Saved searches.
- Concurrent multi-location local search with one tab per location.

## Next milestones

1. Import mapping UI, Excel support, duplicate-review queue, and search filters.
2. PostgreSQL/PostGIS implementation and map/radius search.
3. Permitted self-hosted open-data import pipeline with license attribution.
4. Authentication, organizations, roles, audit log, and API keys.
5. Worker queue, observability, backup/restore, and load benchmark suite.

No roadmap item authorizes scraping prohibited sources, CAPTCHA bypasses,
restriction evasion, or use of data outside its license or contract.
